# 레마넥트 PC 프로그램 — 내려받기

㈜레마넥트(Rhemanect Co., Ltd.)가 만든 Windows 프로그램의 **설치 파일**을 올려 두는 곳입니다.
프로그램 소스는 이 저장소에 없습니다. 설치 파일은 [Releases](https://github.com/saguim2018/rhemanect-apps/releases)에 있습니다.

| 프로그램 | 하는 일 | 안내 페이지 |
|---|---|---|
| **셈판** | 엑셀 파일(.xlsx·.xls·.csv)을 열고 고치고 저장하는 표 계산 프로그램 | https://rhemanect.com/apps/sempan |

## 설치하기 전에

- 서명 인증서를 아직 붙이지 않아 Windows SmartScreen 경고가 뜰 수 있습니다. **추가 정보 → 실행**을 누르면 설치됩니다.
- 받은 파일이 원본인지 확인하려면 안내 페이지의 SHA-256 값과 비교해 주세요.
  PowerShell: `Get-FileHash .\Sempan-Setup-<버전>.exe -Algorithm SHA256`
- 무료이며 광고와 계정 가입이 없습니다. 사용 조건은 [사용권 계약](https://rhemanect.com/apps/terms), 개인정보는 [처리 안내](https://rhemanect.com/apps/privacy)에 있습니다.
